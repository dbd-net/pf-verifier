Provably fair verifier

Check a happyending.com pack opening yourself. Paste the values from the round's proof page. Everything runs in your browser: nothing you enter is sent anywhere.

1. SHA-256 of the server seed
2. HMAC-SHA256 message (the server seed is the key)
HMAC-SHA256 output
3. Ticket (1 to 1,000,000)

The round's proof page on happyending.com shows which item's ticket range this ticket falls in.

Read the code: verify.js (about 40 lines). Prefer your own tools? The README shows how to do the same check with any SHA-256 and HMAC calculator.
